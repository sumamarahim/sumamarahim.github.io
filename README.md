# Sumama Rahim - Academic & Research Portfolio Website

This package contains the complete set of independent static HTML pages for **Sumama Rahim**, BS Computer Science undergraduate at National Skills University, Islamabad.

## File Structure
- `index.html` — Homepage with academic snapshot and exploratory research interests
- `about.html` — Academic journey, learning approach, and values
- `research.html` — Interdisciplinary research interests (AI/ML, Cybersecurity, Software Eng, Networks, Data Science)
- `projects.html` — Technical projects and SRS specifications
- `education.html` — Timeline, CGPA, coursework, and certifications
- `experience.html` — Student leadership and extracurricular roles
- `teaching-competitions.html` — Teaching underprivileged students, hackathons, and languages
- `contact.html` — Direct academic contact and inquiry form
- `assets/css/style.css` — Modular stylesheet
- `assets/js/main.js` — Core JavaScript

## Deployment
Upload these files directly to GitHub Pages, Netlify, or Vercel static hosting. No build step or Node.js required!
